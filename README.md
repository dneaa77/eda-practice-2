# Практика №2 — EDA Wine Quality

## Цель
Провести исследовательский анализ данных Wine Quality.

## Датасет
- Источник: UCI Machine Learning Repository
- Файл: winequality-red.csv
- Формат: CSV
- Размер: 1599 строк, 12 столбцов
- Целевая переменная: quality

## Инструменты
- Python
- VS Code
- Jupyter Notebook
- pandas
- NumPy
- Matplotlib
- Seaborn

## Виртуальное окружение
Используется venv для изоляции библиотек проекта.

## Структура
- data/ — исходные данные
- notebooks/ — анализ
- README.md — описание проекта

## Выполненные задачи
1. Общий осмотр и типы признаков.
2. Проверка пропусков и статистики.
3. Распределения и выбросы.
4. Частоты и редкие оценки.
5. Корреляционная матрица.
6. Диаграммы рассеяния.
7. Анализ распределения целевой переменной.
8. Итоговый отчёт с дальнейшими действиями.
